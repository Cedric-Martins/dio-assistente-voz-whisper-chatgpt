# Assistente de Voz Multi-Idiomas com Whisper e ChatGPT

Projeto desenvolvido durante o desafio da DIO.

## Tecnologias utilizadas

- Python
- OpenAI Whisper
- ChatGPT
- Google Text-to-Speech (gTTS)
- Google Colab

## Funcionalidades

- Captura de áudio pelo microfone
- Conversão de voz para texto
- Geração de respostas utilizando ChatGPT
- Conversão da resposta em áudio

## Fluxo

1. Usuário grava um áudio.
2. Whisper realiza a transcrição.
3. O texto é enviado ao ChatGPT.
4. O ChatGPT gera uma resposta.
5. A resposta é convertida para voz com gTTS.
